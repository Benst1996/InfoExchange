# Information Exchange API
An ASP .NET API service for exchanging information between two parties. This README is written in markdown. Open this README in an editor/viewer that supports markdown for a recommended reading experience.

## Usage
To run the service:
- Download and unzip the main folder.
- Start Visual Studio Code (VSCode) and open the folder in VSCode.
- Make sure .NET 10.0 is installed.
- Open a terminal in VSCode and execute `dotnet run`.

Once the service is running HTTP GET requests can be sent. Some example requests in the expected format can be found in [InfoExchange.http](InfoExchange.http). Open this file in VSCode and press `Send Request` on any request to send the request and to receive the contents of the files that are requested.

## Notes
This project was made using Minimal API instead of API with controllers.

Core files were generated by using the `dotnet new webapi -f net10.0` command. The main files that were changed from the template are [Program.cs](Program.cs) and [InfoExchange.http](InfoExchange.http).

## Known issues
- Logger does not log which files have been exchanged.
- HTTP POST, PUT and DELETE requests are not supported.
- Valid GET requests return the file's contents not the file itself.
- No validation checks are performed.
